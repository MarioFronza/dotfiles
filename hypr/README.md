# hypr

Personal overrides on top of Omarchy's default Hyprland setup. These files
`require()` and `dofile()` into `$OMARCHY_PATH`, so this only works on an
[Omarchy](https://omarchy.org) install — plain Hyprland won't resolve them.

## Install (Arch)

Omarchy already ships Hyprland and its defaults. Nothing to install beyond
Omarchy itself:

```bash
# from https://omarchy.org (installs Arch + Hyprland + Omarchy defaults)
curl -fsSL https://omarchy.org/install | bash
```

## Link

```bash
mkdir -p ~/.config/hypr
for f in hyprland.lua monitors.lua input.lua bindings.lua looknfeel.lua autostart.lua \
         hypridle.conf hyprlock.conf hyprsunset.conf xdph.conf; do
  ln -sf "$(pwd)/$f" ~/.config/hypr/"$f"
done
```

Note: `hyprmoncfg-monitors.lua` (generated by `hyprmoncfg`, monitor layout)
is machine-specific and intentionally not tracked here — Hyprland's
`hyprland.lua` `dofile`s it directly from `~/.config/hypr/`, so just let it
regenerate on each machine.

## Apply

```bash
hyprctl reload
hyprctl configerrors   # check for errors after reload
```
